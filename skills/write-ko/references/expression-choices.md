# 문맥에 따른 표현 선택

이 문서는 문장을 생성할 때 참고하는 선택 안내다. 왼쪽 표현을 발견했다고 오른쪽 표현으로 자동 치환하지 마라. 문맥·행위자·논리 관계·확신 수준·말투를 먼저 판단하라.

## 의미가 같을 때 간결한 표현을 선택하라

| 표현 후보 | 간결한 선택 | 판단할 점 |
|---|---|---|
| 검토를 진행한다 | 검토한다 | 진행 중인 상태가 핵심이면 '검토 중이다'를 써라 |
| 확인을 실시한다 | 확인한다 | 확인이 실제로 이루어졌는지 시제와 사실을 맞춰라 |
| 시간이 소요된다 | 시간이 걸린다 | 사용자가 정한 공적 문체가 있으면 고려하라 |
| 자료를 송부한다 | 자료를 보낸다 | 특정 법률·계약 용어를 임의로 바꾸지 마라 |
| 연결 상태에 대한 확인 | 연결 상태 확인 / 연결 상태를 확인한다 | 제목과 본문에 맞게 고르라 |
| 결과가 보여진다 | 결과가 보인다 | 관찰인지 추론인지 구분하라 |

## 뜻이 달라질 수 있는 표현은 관계를 먼저 정하라

| 표현 | 보존할 의미 | 선택 기준 |
|---|---|---|
| 내려받을 수 있도록 한다 | 가능하게 만드는 행위 | 실제 조치가 주어졌을 때 그 조치를 써라. 단순한 가능 상태로 바꾸지 마라 |
| 하도록 한다 | 지시·사동·약속 중 문맥의 의미 | 다른 사람에게 맡기는 행위라면 주체와 역할을 보존하라 |
| 하는 것이 좋다 | 권고 | '해야 한다'나 명령형으로 일괄 강화하지 마라 |
| 할 수 있다 | 능력·허용·가능성 | 무엇을 뜻하는지 문맥으로 구별하고 필요하면 풀어라 |
| 일 수 있다 | 가능한 해석이나 상태 | 근거 없이 단정하거나 가능성이 높다고 쓰지 마라 |
| 약 30분 | 근삿값 | 정확한 30분이나 보장된 완료 시간으로 바꾸지 마라 |
| 일부 / 대부분 | 범위나 비율의 제한 | 알려진 수치가 있을 때만 수치로 구체화하라 |
| 변경 이후 | 시간적 선후 관계 | 인과관계가 확인되지 않으면 '변경 때문에'라고 쓰지 마라 |
| 불가능하지 않다 | 가능성을 배제하지 않음 | 실현 가능성이 확인되었다는 주장으로 높이지 마라 |
| 저장되어 있다 | 저장된 상태 | 상태가 주제라면 행위자를 억지로 추가하지 마라 |
| 처리 중이다 | 아직 완료되지 않은 상태 | 실제 작업이 알려졌을 때 구체화하되 완료로 쓰지 마라 |
| A에 대한 의견 | 의견의 대상 | 'A의 의견'으로 바꾸면 의견의 주체가 달라질 수 있다 |
| A를 위한 B | 목적·수혜 관계 | 목적어와 목적 관계를 혼동하지 마라 |

## 전문 용어와 자연스러운 표현을 허용하라

- '압착', '결선', '멱등성'처럼 정확한 개념을 나타내는 말은 유지하라. 쉬운 말이 실제 작업이나 의미를 바꾸면 대체하지 마라.
- 전문 용어는 정의와 필요한 사례를 함께 써라. 멱등성을 설명할 때 '매번 실제 데이터 변경이 한 번 일어난다'고 일반화하지 마라. 반복 요청의 의도된 효과가 같다는 의미에 맞춰라.
- '대한', '통해', '위해', '관련'은 관계를 정확하고 자연스럽게 표현하면 사용할 수 있다. 관계를 감추거나 불필요하게 늘어날 때만 더 직접적인 표현을 택하라.
- '개선', '최적화'는 주제나 작업 종류를 가리킬 수 있다. 결과를 보고한다면 알려진 변화와 근거를 덧붙이되, 수치를 만들지 마라.
- '혹시', '부탁드립니다', '같습니다'는 대인 관계와 정중함에 필요한 경우가 있다. 사실의 확신 수준과 예의상 완곡함을 구별하라.
- 높임말, 조사, 문장 종결과 시제는 글의 독자와 문맥에 맞춰라. 자연스러운 표현을 특정 어형이라는 이유만으로 금지하지 마라.

## 새 문장을 만들기 전에 확인하라

선택한 표현이 주체, 동작, 상태, 시간, 의무의 강도 또는 확신 수준을 바꾸는지 확인하라. 뜻이 바뀐다면 그 표현을 선택하지 마라. 단어 하나로 해결되지 않으면 같은 정보를 유지하는 다른 문장 구조를 사용하라.
